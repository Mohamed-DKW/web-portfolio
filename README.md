## 🚀 Instalación

Clona el repositorio:

```bash
git clone https://github.com/Mohamed-DKW/web-portfolio.git
```

Accede al proyecto:

```bash
cd portfolio
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:3000
```
